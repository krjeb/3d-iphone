# 3D iPhone Apple Website

An Apple iPhone 15 Pro–inspired 3D product website built with React, Three.js, GSAP, and Tailwind CSS.

## Tech Stack

- **Frontend / Framework:** React, Vite, Tailwind CSS
- **3D & Animation:** Three.js, React Three Fiber, React Three Drei, GSAP (ScrollTrigger, timeline-based video carousel)
